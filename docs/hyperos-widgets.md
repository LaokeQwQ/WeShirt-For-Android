# 桌面小部件

小部件使用原生 Android AppWidget / RemoteViews，参考[小米 HyperOS 小部件设计规范](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1664)。从桌面的小部件菜单添加 WeShirt·洗衣；小米设备也可从“安卓小部件”入口添加。小米小部件中心收录需另外提交审核，本项目不声称已经获得收录。

卡片围绕自己的洗衣任务展示：没有任务时显示“空闲”，有任务时显示机号、二维洗衣机、剩余分钟和进度。右上方为“更新于 HH:mm”和独立的顺时针刷新按钮。最小尺寸为 180×140dp，较高的卡片补充状态说明。Android 12 及以上使用响应式 RemoteViews，旧系统在用户缩放后重新选择布局。颜色跟随系统深浅模式，提供中文、英文和放大字体支持。

应用内刷新会同步更新卡片。点击刷新按钮通过 WorkManager 在后台重新读取登录状态、权限、住宿楼和本人任务，不打开应用；重复点击合并，最短请求间隔为 30 秒。失败时保留原数据并标记待更新，错误附状态码和事件编号。快照按服务、账号与会话隔离；退出后不再显示，旧请求不能覆盖新账号。快照不保存昵称、联系方式、聊天、公开洗衣备注或推送凭据。小组件不依赖通知开关或通知权限。

运行时机身保持静态，原生 ViewFlipper 播放滚筒，原生进度条叠加活动效果。百分比按可信的任务起止时间计算，缺少开始时间时显示“进度待确认”。有限的本地分钟重绘推进剩余时间，十分钟后停止并提示更新，不进行每秒网络轮询，也不使用后台常驻服务或精确闹钟。到点显示“即将完成”，不能据此判断机器空闲；设备确认完成后显示“待取衣”。空闲、过期或待确认状态会移除滚筒动画，避免隐藏的动画继续运行。系统省电和桌面实现可能延迟重绘与后台请求，不能保证分钟级准时执行。

验收需覆盖实际桌面提供的 2×2、4×2、4×4 网格、浅色与深色、中文与英文、放大字体、退出账号和离线旧数据。不同启动器的网格占用和内边距可能不同，应以真机桌面为准。

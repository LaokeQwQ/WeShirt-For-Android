# 桌面小部件

小部件使用原生 Android AppWidget / RemoteViews，参考[小米 HyperOS 小部件设计规范](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1664)。从桌面的小部件菜单添加 WeShirt·洗衣；小米设备也可从“安卓小部件”入口添加。小米小部件中心收录需另外提交审核，本项目不声称已经获得收录。

窄卡片优先显示当前任务的预计完成时刻，没有任务时显示楼栋空闲数量。宽卡片并排显示楼栋统计与当前任务；较高的卡片补充使用中、未知数量和两个直接入口。Android 12 及以上使用响应式 RemoteViews，旧系统在用户缩放后重新选择布局。大字体优先使用精简布局，颜色跟随系统深浅模式，提供中文和英文资源及功能说明。

数据来自应用已有的楼栋查询结果，不增加网络轮询、后台服务或精确闹钟。卡片标明同步时间；已知超过十分钟的结果标为历史数据，时间无效时隐藏数量。退出账号会清空快照。快照不保存昵称、联系方式、聊天、公开洗衣备注或推送凭据。

完成时间只作估计，不能用于判断机器空闲。卡片显示绝对预计时刻而非持续倒数；后台未刷新时不会越过零点变成负数，也不会自行宣称洗衣已完成。宽卡片的当前时间由系统 TextClock 更新。设备真正确认结束后，由应用的正常同步更新卡片。

验收需覆盖实际桌面提供的 2×2、4×2、4×4 网格、浅色与深色、中文与英文、放大字体、退出账号和离线旧数据。不同启动器的网格占用和内边距可能不同，应以真机桌面为准。

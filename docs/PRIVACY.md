# 隐私与发布检查

应用只向用户选择的 WeShirt 服务发送业务请求。钉钉授权通过安装的钉钉客户端进行，应用不收集钉钉密码。

令牌不写入日志、二维码、通知或小组件。小组件仅保存楼栋名称、机器数量、任务名称和预计时间；退出账号后清理。设备端提醒显示私密通知，锁屏隐藏业务正文。

聊天和上传附件由服务端校验当前楼栋、频道和操作权限。公开登记备注、消毒液及自清洁记录会显示在机器状态面板，请勿填写私人联系方式。

远程推送 SDK 在取得通知同意、完成配置后初始化。未配置渠道不会假报成功。具体 SDK 的设备数据处理以供应商隐私政策为准，部署方应在提供服务前补充自己的隐私政策和联系方式。

关闭通知或开屏公告立即在本机生效，不等待网络或其他写操作。服务端同步失败会显示可追溯错误；旧的开启请求返回后也不能恢复已撤回的本机选择。

匿名性能选项默认关闭，位于隐私设置。性能统计不得包含账号、手机号、聊天、公开备注、访问令牌或推送设备令牌。

公开提交前检查：本地配置、keystore、签名密码、服务端密钥、正式学校信息、真实账号记录和云端部署输出均不得进入 Git。CI 使用无凭据构建；公开工作流不执行签名分发。

# 安卓原生管理员后台

后台入口位于设置页，只在服务端返回 `adminVisible: true` 时显示。页面使用 Compose 表单、原生选择器、确认弹窗和原生 Markdown 预览；不使用 WebView，也不要求管理员输入或编辑原始 JSON。

## 功能对应

| 页面 | 原生操作 | 服务端权限 |
| --- | --- | --- |
| 概览与同步 | 授权楼栋统计、楼层摘要、同步状态、手动同步 | `adminDashboard`；手动同步另需 `adminSystem.operate` |
| 用户管理 | 按楼栋/关键词查询、昵称与通知偏好、住宿楼调整、全号按需查看、钉钉解绑、删除、历史资料补全 | `adminUsers`；批量补全需全部楼栋操作范围 |
| 机器与机位 | 按楼栋查询状态、预计完成时刻、登记人、排队人数，清除本地登记/排队，3D 机位绑定 | `adminMachines`；机位编辑需全部楼栋操作范围 |
| 内容治理 | 举报筛选/分页/处理说明、消息删除/置顶、全部清空、定时或永久禁言、解除禁言 | `adminMessages`，置顶另需频道消息操作权限 |
| 上报审计与日志 | 日志类型/等级/时间/关键词查询，系统文件选择器导出 CSV，上报统计、凭证照片、旧照片清理 | `adminAudit`；旧照片清理另需 `adminSystem.operate` |
| 网站与楼栋 | 网站名称、图标地址、学校显示名/ID、住宿楼添加与启停、钉钉通道、楼栋群、后台成员与志愿管理范围 | `adminSite` 与接口返回的细分能力 |
| 成员功能权限与范围 | 搜索真实用户、各功能查看/操作开关、各自楼栋范围、恢复身份默认值 | 仅服务端总管身份 |
| 运营与通知 | 定点播报启停、起止小时、自定义小时、管理员通知已读/解决、钉钉通道诊断和真实测试 | `adminOperations`；回调统计重置另需 `adminSystem.operate` |
| 开屏公告 | 列表/新建/编辑/删除、按楼发布、发布时间段、草稿/发布、Markdown 工具栏和原生预览 | `adminAnnouncements` 与楼栋范围 |
| 性能统计 | 周期与楼栋筛选、接口耗时/失败、页面指标、3D 帧率/质量、最近错误事件 | `adminTelemetry` 与查看范围 |
| 模型配置 | Responses 兼容 HTTPS 端点、模型、调用上限、替换或清除密钥 | `adminAssistant` |
| 上游与系统 | 账号池、授权更新、短信登录、导入、存活检测、上游连接诊断、定时同步建议 | `adminSystem` |

网站图标采用与 Web 后台相同的 HTTPS 地址或站内路径表单；频道头像上传由原生频道管理提供。当前服务端楼栋目录字段为代号、名称、启用状态，原生后台不会发送不存在的楼栋图标或分类字段。上游与系统的接口和敏感值处理另见 [native-admin-system.md](native-admin-system.md)。

## 会话与权限

使用主应用现有 Bearer 会话，未增加静态管理员口令。导航按 `/api/user/permissions` 的每项 `view` 显示，操作按 `operate`、具体目标楼栋和接口细分能力控制；空权限、缺失范围或异常范围结构按无授权处理。禁言目标、角色上限、最后一名总管及所有请求仍由服务端实时校验。

后台请求绑定进入时的用户及服务地址，账号或端点改变后拒绝旧结果。离开后台取消页面作用域，删除屏幕数据；后台开启截屏保护。提交期间阻止重复提交，切换页面不会额外启动轮询。网络错误复用统一请求层的状态码与事件 ID。

密钥、token、短信验证码和导入文本仅存在当前表单内存，不放入可恢复状态、磁盘或日志；提交结束与离开表单时清空，服务端原值不回显。诊断只呈现明确允许的摘要字段，不显示上游完整请求、学校点位参数、原始响应或带密钥的同步地址。

CSV 仅在管理员确认并选择目标文件后生成，沿用服务端的类型、级别和天数筛选；当前服务端 CSV 不支持关键词筛选，界面在导出确认中说明这一差异。凭证照片从已有鉴权接口按需读取，限制编码体积、解码像素和显示分辨率，不建立公开图片地址或额外缓存。公告预览使用原生文本组件，预览中的链接不打开浏览器，也不请求外部图片。

## 验收

原生页面应覆盖总管、管理员、仅查看、指定楼栋和权限被撤回的账号；检查列表查询、单目标操作及批量操作的服务端拒绝行为。短信、真实钉钉测试、删除、授权变更和清理必须由管理员在确认弹窗后执行，自动测试不触发生产动作。

`AdminScopeTest` 覆盖公共频道与楼栋范围的区分、查看不能操作、异常范围拒绝、显式全部范围。小部件的独立验收见 [hyperos-widgets.md](hyperos-widgets.md)。集成构建、界面测试和设备结果由仓库发布流程统一记录。

# 原生 3D 洗衣房

Android 使用 Filament `SurfaceView` 绘制，场景由本地 Kotlin 网格生成，不依赖 WebView、网页或远程 3D 页面。无场景绑定或渲染器创建失败时，界面回到原生机器列表。

## 与 Web 对齐范围

参照 Web 的 `Room3D.vue`、`room/garments.js`：

- 房间尺寸、入口朝向、两侧机位 D1/1–4 与 D2/7/6/5、洗衣机和烘干机比例保持同一套布局。
- 保留窗户、开水机、配电设施、投料设备、墙面须知、入口鞋架、拖把等设施。点开水机和须知展示原生说明，窗把手和水龙头可切换视觉状态。
- 衣物采用相同的衣领、袖子、裤腿轮廓、三件配色、折面与堆叠变换；翻滚仅更新变换，不逐帧生成网格。
- 空闲门打开，运行关门；洗衣运行显示水位，烘干无水；故障显示叉号；排队用最多三个待洗桶展示。水、衣物和排队桶以服务端状态驱动，倒计时归零不会在场景中改成空闲。
- 点机器平滑聚焦，拖动或缩放可接管镜头；双击或全景按钮复位。原生底部机器入口和设施须知支持不依赖场景命中的操作。

Filament 与 Three.js 的光照、色彩管理、透明水面和文字材质不同，原生使用合批材质与简化水位表现，并不声称像素一致。机器业务面板复用 Android 原生详情界面，登记、排队及留言由同一份机器数据驱动。

## 帧率和资源

自动模式从完整分辨率和屏幕可用帧率开始。首 8 秒不训练掉帧判断，随后要求连续三个 2 秒采样窗出现持续压力才降级；两次调整至少相隔 30 秒，恢复也要求持续性能余量。先降低帧率，后降低分辨率。每次性能降级由界面显示 3 秒提醒，省电与温控限制优先。

静止场景无持续渲染循环；运行衣物、门或镜头动画才请求后续帧。切到后台停止帧回调；视图释放销毁本地缓冲、实体和 Filament 资源。系统关闭动画时停止惯性和翻滚，镜头与门直接到位。模型含最大队列的测试预算为 120,000 顶点。

## 验收边界

单元测试覆盖机位与命中、网格索引/有限数/预算、衣物形状、队列上限、设施点击、镜头收敛、预热/降级/冷却/恢复。发布前仍需在真实 Android 设备上检查画面遮挡、触摸和帧率；模拟器和编译通过不能代替真机画面验收。

# Web 功能与原生入口

Android 使用 Kotlin、Compose Material 3 和 Filament，界面、聊天、后台及 3D 均不加载 WebView。业务继续使用同一服务、账号、权限和数据。这里记录功能入口；平台配置成功与真机授权、推送送达验收是不同阶段。

| --- | --- |
| 按楼栋机器状态、楼层、最快可用排序 | 洗衣房；洗衣/烘干分类、默认列表与卡片切换、收藏筛选、更新时间与陈旧提示 |

## Android 平台功能

- FCM 优先，注册不可用时回退基础 U-Push；不接入 Xiaomi Super Island 或 MiPush。小部件适配尺寸及深浅色，Android 标准进度通知由系统决定展示形式。
- 相机在拍照/录像时申请权限，录制有声音的视频时申请麦克风。相册使用 Photo Picker，文件使用系统文档选择器；不申请访问全部文件或整个相册。视频最终校验不超过 30 秒/8MB，照片压缩并移除元数据。
- 邀请支持相机扫码、粘贴、系统分享文字和当前打包服务的 HTTPS 链接。外部链接必须匹配当前服务，先预览再确认，不能自动切换服务。Android 未验证域名默认可能由浏览器打开，可用系统“分享给 WeShirt”进入原生处理。
- Web Push、浏览器缓存/安装和网页 OAuth 由原生通知、应用本地缓存与拉起钉钉替代，不在 APK 内嵌网页。模型、MCP、同步任务和群播报继续在云端运行。
- 机器面板固定标题、关闭与登记按钮，详情单独滚动，排队/现场反馈按需展开，适配窄屏、横屏和大字号。动态 JSON API 不复用 HTTP 缓存；新看板先显示，队列、占用、通知等附加请求失败会单独提示，不阻止机器状态更新。更新时间仍保留数据源时间，不把刷新时间当成设备更新时间。
- 同楼栋收到较旧快照会保留已展示的新数据，换楼栋正常替换；最近设备同步失败或数据滞后会持续显示提示，失败提示保留服务端事件编号。
- 服务地址集中在「我的 → 通用」，位于「显示与性能」上方。切换服务仍需退出当前会话，授权回调仅能兑换到原先发起登录的服务。

## 验证边界

自动检查覆盖编译、静态检查、状态与排序、签名邀请解析、权限范围、并发和旧会话隔离，以及设备上的原生控件/推送路由等。生产密钥不进入仓库、公开 CI 或测试夹具。真实钉钉授权、FCM/U-Push 到达、拍摄设备与各品牌后台限制仍需使用正式签名包在对应真机验收。
